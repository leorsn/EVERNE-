## Recommended first physical batch

Do **not** order 25 or 50 sets before sample approval.

Sequence:

1. Order one sample of each of the four physical components.
2. Compare geometry, colour, material, finish and dimensions against the current EVERNE imagery and product copy.
3. Perform basic textile-use testing and photograph the actual products together.
4. Resolve manufacturer / EU responsible-person and GPSR information.
5. Unlock the Faire Fabric Shaver wholesale price and Germany shipping terms.
6. Recalculate true landed cost.
7. If all four pass, place a **10-set controlled launch batch** first.
8. Only reorder 25+ sets after the first real orders validate demand, product quality and returns.

## Current release blockers

- Fabric Shaver wholesale cost and Germany delivery terms not yet visible.
- Everful Soft Care Brush Germany shipping/import treatment not yet verified.
- Soft Care Brush intended-use/product-documentation mismatch must be resolved before marketing it as textile care.
- SHEIN lint-brush source needs physical Blue/Pink colour and geometry validation.
- All products need manufacturer / responsible economic operator data adequate for EU/GPSR obligations.
- Customer returns and reverse-logistics address/process must be fixed before commerce opens.

## Decision

The current data supports a **small-stock launch strategy**, not blind direct-to-consumer dropshipping. Product-cost economics appear workable. The next spending decision should be limited to samples, followed by a 10-set batch only after validation.
